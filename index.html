Options gamma exposure (GEX) on a TradingView-style chart

TradingView GEX by FlashAlpha is an open-source JavaScript chart that draws options gamma exposure (GEX) indicators on the candles: call wall, put wall, gamma flip, max pain, 0DTE magnet, net GEX, a strike heatmap, a GEX profile, an expiry heatmap, the expected move, level events and the 0DTE hedging flow. It is built on TradingView Lightweight Charts™ and reads data from the FlashAlpha options analytics API. The chart is free under the MIT license; the data needs a FlashAlpha API key. The source code is on GitHub.

Indicators

  • GEX Levels: call wall, put wall, gamma flip, max pain and the 0DTE magnet, drawn bar by bar, with the gamma regime tint behind the candles. Basic plan.
  • Net GEX: net dealer gamma exposure in dollars, in a pane under the price. Basic plan.
  • Strike heatmap and GEX profile: net GEX per strike behind the candles and as bars at the right edge, each with GEX, DEX, VEX and CHEX lenses. Growth plan.
  • Expiry heatmap: gamma by strike and by expiration in a panel beside the chart, with totals per strike and per expiration. Growth plan.
  • Greeks and 0DTE metrics: delta, vanna or charm exposure, or a 0DTE metric such as the pin score, IV ratio, VIX or dealer hedge per ±1 %. Basic (Greeks), Growth (metrics).
  • 0DTE scope and live open interest: the same indicators on today's expiry only, or on open interest updated with today's flow. Growth (0DTE), Alpha (live OI).
  • Expected move: the options-implied 1σ range of each session from its open, and how often the price stayed inside it. Growth plan.
  • Level events: where the price was rejected at a GEX level, broke it or crossed the gamma flip; regime flips, OPEX and earnings days. Growth plan.
  • 0DTE hedging flow: the stock dealers had to buy or sell to hedge today's 0DTE trades, with divergences against the price. Growth plan.

Add the chart to your site

<div data-flashalpha-chart data-symbol="SPY" data-resolution="5m"
     data-layers="levels,maxpain,netgex" style="height: 520px"></div>

<script async src="https://charts.flashalpha.com/embed.js" data-key="YOUR_FLASHALPHA_API_KEY"></script>

In an app, install it from npm with npm install tradingview-gex-flashalpha, next to its peer dependency TradingView Lightweight Charts 5.3.0. On a public page, use an embed key so your secret API key never reaches the browser. All options are in the README and the chart API reference.

FAQ

Is this a TradingView Pine Script indicator?
No. It is a chart you embed on your own website or app, built on TradingView's open-source Lightweight Charts™ library. It looks and works like a TradingView chart, but it runs outside tradingview.com and reads FlashAlpha data directly.
Is it free?
The chart is free and open source under the MIT license. FlashAlpha data needs an API key: the free plan shows candles and volume, GEX Levels and Net GEX start on Basic, and the strike heatmap, GEX profile, expiry heatmap, expected move, level events, 0DTE hedging flow and 0DTE scope are on Growth. With your own data source you need no key at all. See plans and pricing.
Which symbols and timeframes are supported?
US stocks, ETFs and indices that the FlashAlpha chart API lists, such as SPX, SPY, QQQ, AAPL, MSFT and TSLA, on 1-minute, 5-minute, 15-minute, 1-hour, daily and weekly bars.
How often do the indicators update?
Every 60 seconds while the page is visible, and in real time with the optional live WebSocket mode.
Can I put the chart on my website?
Yes, with one div and one script tag, or with the npm package in your app. Use an embed key on public pages so your secret API key never reaches the browser.
